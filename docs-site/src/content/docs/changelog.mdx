## 1.0.1 (2026-11-02)

- Streamed calls now dispatch `WorkersAiUsageReported` with the call's neuron total. Before, only non-streamed calls reported neurons. See [Cost tracking](/guides/cost-tracking/).

## 1.0.0 (2026-11-02)

First stable release. One codebase supports `laravel/ai` 0.9 to 1.3.

- Adds `laravel/ai` 1.x support (`^1.0`, tested on v1.0.0 and v1.3.0).
- Sends the `headers` config key and, on 1.x, `Provider::withHeaders()` headers. Before 1.0.0 they were dropped.
- Fills `StepResponse::$reasoning` on 1.x.
- On 0.9 to 0.11, `Usage::$promptTokens` excludes cached tokens. On 1.x, `TextUsage::$inputTokens` includes them. `WorkersAiUsageReported::$promptTokens` is uncached on both.
- Fixes 6 attempts on a persistent 429 with `laravel/ai` 1.2.1 and later. The total is 3 again.
- Reads `reasoning_tokens` from `completion_tokens_details` too.

Upgrading from 0.8.x? See [Upgrade to 1.0](/guides/upgrade/).
