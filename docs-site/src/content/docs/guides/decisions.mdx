Clef and Clairic are System One models on Workers AI. They do not write text. Clef picks among options you list. Clairic returns a typed value, or null when the input does not determine it.

Jev, the TypeSafe model laravel/ai's classification API was built for, is not a Workers AI model. The same API drives Clef, because Clef speaks the same request. Clairic does not, so it has its own entry point.

## Clef

Needs `laravel/ai` 1.0 or later. On 0.9 to 0.11, `Classification` does not exist and this call is not registered. Clairic still works on those versions.

```php
use Laravel\Ai\Classification;
use Laravel\Ai\Classification\Boolean;
use Laravel\Ai\Classification\Choice;
use Laravel\Ai\Classification\Score;

$response = Classification::of('Checkout has been failing for every customer for the last hour.')
    ->questions([
        'urgent' => new Boolean('Is this support request urgent?'),
        'team' => new Choice('Which team should handle this request?', [
            'billing' => 'Payments, invoices, and refunds',
            'technical' => 'Outages, errors, and configuration',
        ]),
        'severity' => new Score('How severe is the customer impact?', [
            'No impact', 'Minor', 'Major', 'Critical',
        ]),
    ])
    ->classify(provider: 'workers-ai');

$response['urgent']->isTrue();          // probability >= 0.5
$response['urgent']->probability;       // 0.0 to 1.0
$response['team']->choice;              // 'technical'
$response['severity']->score;           // probability-weighted level
```

The default model is `@cf/cloudflare/clef`. Pass a model to use another:

| Model | Selector the body sends | Use |
| --- | --- | --- |
| `@cf/cloudflare/clef` | `clef` | Highest-precision decisions. Default. |
| `@cf/cloudflare/clef-flash` | `clef-flash` | Faster and cheaper. `cheapestClassificationModel()`. |
| `@cf/cloudflare/clef-omni` | `clef-omni` | Also reads audio and video. This package sends images only. |

```php
->classify(provider: 'workers-ai', model: '@cf/cloudflare/clef-flash');
```

Set the default in config with `models.classification.default`.

Up to four JPEG, PNG or WebP images go in Clef's `images` field. They are not placed inside the state, which is what Jev does. A fifth image throws before a request. Image attachments need `laravel/ai` 1.2 or later. Audio and video, which only Clef-omni accepts, are not mapped.

```php
use Laravel\Ai\Files\Image;

Classification::of('A product photo uploaded by a customer.', [
    Image::fromPath(storage_path('app/photo.jpg')),
])->question('damaged', new Boolean('Is the product damaged?'))
    ->classify(provider: 'workers-ai');
```

`Str::decide()` and `Classification::fake()` work, because those are laravel/ai. Point the fake or the call at `workers-ai`.

## Clairic

Clairic takes fields, not questions. A field is a type. The answer is a value of that type, read from the input, computed from it, or predicted past it. `value` is null when the input does not determine it, and `p_null` is the probability of that.

```php
use Meirdick\WorkersAi\Extraction;
use Meirdick\WorkersAi\Extraction\DateField;
use Meirdick\WorkersAi\Extraction\Estimate;
use Meirdick\WorkersAi\Extraction\Number;
use Meirdick\WorkersAi\Extraction\Text;

$invoice = Extraction::of($text)
    ->fields([
        'invoice_number' => new Text,
        'due_date' => DateField::date('Issue date plus the net payment days'),
        'total' => new Number(
            instructions: 'Amount due including shipping',
            decimals: 2,
            unit: 'USD',
        ),
        'days_to_pay' => new Estimate(
            min: 0,
            max: 120,
            step: 1,
            instructions: 'Days after issue until this invoice is paid',
        ),
    ])
    ->referenceDate('2026-11-03')
    ->extract();

$invoice['invoice_number']->value();     // 'INV-2291', or null
$invoice['invoice_number']->span();      // [8, 16], offsets into the state
$invoice['invoice_number']->pNull();
$invoice['invoice_number']->isPresent(); // value set, and p_null <= 0.5
$invoice['days_to_pay']->median();
$invoice['days_to_pay']->p10();
$invoice['days_to_pay']->p90();
$invoice->truncated;                     // true when the state was cut
```

Field types:

| Class | Wire type | Returns |
| --- | --- | --- |
| `Text` | `text` | A span of the state, or null. |
| `Number` | `number` | A number. Set `decimals`, `integer` or `unit`. |
| `DateField::date()` | `date` | An ISO date. Also `time()`, `dateTime()`, `duration()`. |
| `ListField::of('text')` | `list` | A list. Items are `text`, `number` or `date`. |
| `Estimate` | `estimate` | A median, a mean and an 80% interval. `min` and `max` are required. |
| `Forecast` | `forecast` | One estimate per step. Also needs `horizon` and `interval`. |

The model is `@cf/cloudflare/clairic`. Override it with `models.extraction.default`, or pass `model:` to `extract()`. A model that is not Clairic throws before a request.

`referenceDate()` anchors a date written without a year. `withProviderOptions()` can add Clairic's `options`, such as `return_state_text`. It cannot replace `model`, `state`, `fields` or `images`.

Images use the same four-image rule as Clef. A blank state is allowed when an image is sent. A blank state with no image throws.

## Where the request goes

Chat and embeddings use `/ai/v1` or `/compat`. Clef and Clairic do not. Both post to `POST /accounts/{account}/ai/run/{model}`, which is the path Cloudflare documents for these models.

| Config | Run URL |
| --- | --- |
| `account_id` | `https://api.cloudflare.com/client/v4/accounts/{account}/ai/run/{model}` |
| `account_id` and `gateway` | The same URL, plus a `cf-aig-gateway-id` header. |
| `url` ending in `/ai/v1` | The `/ai/v1` suffix is rewritten to `/ai/run/{model}`. |
| `url` ending in `/compat` | Throws. `/compat` does not serve these models, and the URL has no account to build a run path from. Set `account_id`. |

Write bare `@cf/...` IDs. A `workers-ai/` prefix is stripped. The path ID and the body's `model` selector are different: the path is `@cf/cloudflare/clef`, the body is `clef`. The package sends both.

The same `key`, retries and `headers` as chat apply. A 408 is `GatewayTimeoutException`. A 200 that still carries an error envelope throws `AiException`.
