Workers AI chat models don't read document files, so the file has to become text first. Cloudflare's `/ai/tomarkdown` API does that conversion, and the package uses it in two ways: it can run for each document you attach to a prompt, or you can call it yourself.

Cloudflare's list of formats includes PDF, DOCX, XLSX, ODT, ODS, CSV and HTML; see [Markdown conversion](https://developers.cloudflare.com/workers-ai/features/markdown-conversion/) for all of them. Cloudflare says most conversions are free, but images can use paid models.

## Attach a document to a prompt

Set `convert_documents` on the provider entry in `config/ai.php`:

```php
'workers-ai' => [
    // ...
    'convert_documents' => true,
],
```

Then attach a document as you would with any other Laravel AI provider:

```php
use Laravel\Ai\Files\Document;

use function Laravel\Ai\agent;

$response = agent('You answer questions about invoices.')->prompt(
    'What is the invoice number?',
    attachments: [Document::fromPath(storage_path('app/invoice.pdf'))],
    provider: 'workers-ai',
);
```

The package converts the file and adds the text to your message. This works with every chat model, because the model only sees text. Image attachments in the same message stay images.

The setting is off by default, because it makes an extra request you didn't write. With it off, a document attachment throws `InvalidArgumentException`.

The converted text counts toward your token cap and your cost, so a long document can need a higher `#[MaxTokens]` and a model with a larger context window.

## Convert a document yourself

Use `Markdown::of()` when you want the text itself, for example as the input to [Clef](/system-one/clef/) or [Clairic](/system-one/clairic/). It doesn't need `convert_documents`.

```php
use Laravel\Ai\Files\Document;
use Meirdick\WorkersAi\Extraction;
use Meirdick\WorkersAi\Extraction\Number;
use Meirdick\WorkersAi\Markdown;

$text = Markdown::of(Document::fromPath(storage_path('app/invoice.pdf')))->convert();

$invoice = Extraction::of($text)
    ->field('total', new Number(unit: 'USD'))
    ->extract();
```

`Markdown::of()` also takes an uploaded file. To use another provider entry, or a timeout longer than the default 60 seconds, pass them to `convert()`:

```php
Markdown::of($request->file('report'))->convert(provider: 'workers-ai-backup', timeout: 120);
```

Cloudflare sets the output format: a heading and a metadata list, followed by the contents.

## Requirements

- `account_id`, or a `url` that ends in `/ai/v1`. A `url` that ends in `/compat` throws. With `account_id`, calls go to `api.cloudflare.com` even when `gateway` is set, because the package doesn't route this API through a gateway.
- A document with a known type. A file with no MIME type and no file extension throws before the request is sent.

## Errors

| Result | Exception |
| --- | --- |
| Cloudflare cannot read the file | `AiException` that names the file and the reason |
| HTTP 429, 502, 503, 504, 520, 522, 524 after retries | The same failover exceptions as other calls |
| Any other non-2xx status | `Illuminate\Http\Client\RequestException` |

## Test your code

`Markdown` has no fake of its own, so fake the HTTP call:

```php
use Illuminate\Support\Facades\Http;

Http::fake(['*/ai/tomarkdown' => Http::response([
    'success' => true,
    'result' => [['name' => 'a.pdf', 'format' => 'markdown', 'data' => '# Invoice']],
])]);
```
