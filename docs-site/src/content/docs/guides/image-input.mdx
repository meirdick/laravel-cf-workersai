You can attach images to a prompt. The package sends each image as an `image_url` content part. Use a Workers AI model that accepts images.

```php
use Laravel\Ai\Files\Image;

$response = agent('Describe images.')->prompt(
    'What is in this picture?',
    attachments: [Image::fromPath(storage_path('app/photo.jpg'))],
    provider: 'workers-ai',
    model: '@cf/your/vision-model', // replace: see below
);
```

## Supported attachments

| Laravel AI class | Created with | Sent as |
| --- | --- | --- |
| `LocalImage` | `Image::fromPath()` | Base64 data URL |
| `StoredImage` | `Image::fromStorage()` | Base64 data URL |
| `Base64Image` | `Image::fromBase64()` | Base64 data URL |
| `RemoteImage` | `Image::fromUrl()` | The URL |
| Raw `UploadedFile` | Passed as is | Base64 data URL, MIME checked |
| Uploaded file | `Image::fromUpload()` | Base64 data URL (it becomes a `Base64Image`) |

The MIME allowlist (`image/jpeg`, `image/png`, `image/gif`, `image/webp`) applies only when you pass a raw `Illuminate\Http\UploadedFile`, such as `$request->file('photo')`. For other MIME types (SVG, AVIF, HEIC), the package throws `InvalidArgumentException` with the message `Workers AI does not support document attachments. Only image attachments are supported.`

`Image::fromUpload()` returns a `Base64Image`. The package does not check the MIME type of a `Base64Image`, `LocalImage`, `StoredImage` or `RemoteImage`. Cloudflare then accepts or rejects the file. Send only the four types above.

## Not supported

- Documents. The package throws `InvalidArgumentException` with the message `Workers AI does not support document attachments. Only image attachments are supported.`
- Audio and video.
- Image generation.

<Aside type="note">
  The package does not check that the model accepts images. The package author's notes name no vision model. To find one, open the [Cloudflare model catalog](https://developers.cloudflare.com/workers-ai/models/) and filter for models that take image input. Copy its `@cf/...` name.
</Aside>
