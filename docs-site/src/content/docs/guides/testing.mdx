You do not need real Cloudflare credentials to test your own code. Use the Laravel AI fakes. The `Http::fake` example below needs a fake token and account ID in config.

The examples use Pest. For PHPUnit, put the same calls in a test method and replace `expect(...)->toBe(...)` with `$this->assertSame(...)`.

## Fake an agent

```php
SupportAgent::fake(['Reset it from the login page.']);

$response = (new SupportAgent)->prompt('How do I reset my password?');

expect($response->text)->toBe('Reset it from the login page.');

SupportAgent::assertPrompted('How do I reset my password?');
```

With no list of responses, the fake returns `Fake response for prompt: ` followed by the first 10 words of the prompt. You can pass a closure that receives the prompt.

The fake replaces the gateway. No request reaches the package. Use it for your app logic.

## Fake embeddings

```php
use Laravel\Ai\Embeddings;

Embeddings::fake();

// run your code, then:
Embeddings::assertGenerated(fn ($prompt) => $prompt->inputs === ['hello']);
```

## Fake the HTTP layer

To test with the real package code, fake the HTTP call. This checks the request body and the response handling.

```php
use Illuminate\Http\Client\Request;
use Illuminate\Support\Facades\Http;

config([
    'ai.providers.workers-ai' => [
        'driver' => 'workers-ai',
        'key' => 'test-key',
        'account_id' => 'test-account',
    ],
]);

Http::fake([
    'api.cloudflare.com/*' => Http::response([
        'id' => 'chatcmpl-1',
        'object' => 'chat.completion',
        'model' => '@cf/meta/llama-3.3-70b-instruct-fp8-fast',
        'choices' => [[
            'index' => 0,
            'message' => ['role' => 'assistant', 'content' => 'Hello'],
            'finish_reason' => 'stop',
        ]],
        'usage' => ['prompt_tokens' => 10, 'completion_tokens' => 2, 'neurons' => 1.5],
    ]),
]);

$response = agent('You are a helpful assistant.')->prompt('Hi', provider: 'workers-ai');

Http::assertSent(fn (Request $request) => str_ends_with($request->url(), '/chat/completions'));
```

Use `gateway.ai.cloudflare.com/*` as the URL pattern if your test config sets `gateway`.

## Test the neuron event

```php
use Illuminate\Support\Facades\Event;
use Meirdick\WorkersAi\Events\WorkersAiUsageReported;

Event::fake([WorkersAiUsageReported::class]);

// Http::fake(...) as above, then call the agent.

Event::assertDispatched(WorkersAiUsageReported::class);
```

## Live tests

The package repository has live tests that call Cloudflare. They are skipped unless you set `WORKERS_AI_E2E_TOKEN` and `WORKERS_AI_E2E_ACCOUNT`. Set `WORKERS_AI_E2E_GATEWAY` for gateway tests, and `WORKERS_AI_E2E_STRESS=1` for the stress sweep. You do not need them to use the package.
