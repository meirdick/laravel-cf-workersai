laravel-cf-workersai adds Cloudflare Workers AI as a provider for [Laravel AI](https://github.com/laravel/ai) (`laravel/ai`). Run open-weight models from Meta, OpenAI, Moonshot and others on Cloudflare, with the Laravel AI code you already write.

```php
use function Laravel\Ai\agent;

$response = agent('You are a helpful assistant.')->prompt('Say hi.', provider: 'workers-ai');
echo $response->text;
```

## Why use it

- **Same Laravel AI code.** Set the provider to `workers-ai`. Agents, tools and structured output work as with any other provider.
- **Pay for what you use.** Cloudflare bills Workers AI by usage, in neurons. The package reports neuron usage, so you can track cost.
- **Handles Cloudflare's quirks.** A default token cap stops answers being cut at 256 tokens. An empty answer throws an exception instead of returning nothing. Rate limits and edge errors are retried.

## Features

- Text generation, streaming, tool calls and structured output.
- Embeddings.
- Image input for vision models.
- Direct Workers AI API or Cloudflare AI Gateway.
- `reasoning_effort` for reasoning models.

Needs PHP `^8.3` and `laravel/ai` 0.9 to 1.3. Upgrading from 0.8.x? See [Upgrade to 1.0](/guides/upgrade/).
