<h2 class="mt-14 text-2xl font-semibold tracking-tight">Answers, not generated text</h2>

<p class="mt-2 text-muted-foreground">Clef and Clairic are System One models. They don't generate text. They read your input in one pass and return typed answers with probabilities, so you have nothing to parse.</p>

<div class="mt-6 grid gap-4 md:grid-cols-2">
<div class="min-w-0">

**Clef decides** among options you list.

```php
use Laravel\Ai\Classification;
use Laravel\Ai\Classification\Boolean;

$response = Classification::of($ticket)
    ->question('urgent', new Boolean('Urgent?'))
    ->classify(provider: 'workers-ai');

$response['urgent']->isTrue();
```

<LinkButton href="/system-one/clef/" variant="secondary">Clef guide</LinkButton>

</div>
<div class="min-w-0">

**Clairic extracts** a value of the type you ask for, or null.

```php
use Meirdick\WorkersAi\Extraction;
use Meirdick\WorkersAi\Extraction\Number;

$invoice = Extraction::of($text)
    ->field('total', new Number(unit: 'USD'))
    ->extract();

$invoice['total']->value();
```
