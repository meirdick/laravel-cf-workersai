## Why not the built-in driver

Laravel AI can point its `openai-compatible` driver at a `/compat` URL. That path has failed in production. Embeddings returned 401 on an authenticated gateway. A missing token cap cut answers at 256 tokens. An empty reasoning response came back as success.

Use this package for either path. It picks the endpoint, sends the gateway auth header when you set one, and treats Cloudflare's failure modes as failures.

## Cloudflare-only features

- [Clef and Clairic](/guides/decisions/), the System One models Cloudflare hosts. Clef decides. Clairic extracts a typed value.
- A default token cap, `reasoning_effort`, and the neuron figure Cloudflare bills.
- Retries for HTTP 429 and for Cloudflare edge errors.

Needs PHP 8.3 and `laravel/ai` 0.9 to 1.3. Clef needs `laravel/ai` 1.0 or later.
