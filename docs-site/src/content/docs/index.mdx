## What you get

- A default token cap, so answers are not cut at 256 tokens.
- An exception when a reasoning model returns nothing.
- `reasoning_effort`, and neuron figures for what Cloudflare bills.
- Retries for HTTP 429 and Cloudflare edge errors.

Needs PHP 8.3 and `laravel/ai` 0.9 to 1.3. Clef needs `laravel/ai` 1.0 or later.
