## Limits

- Text, embeddings and image input only.
- No document, audio or video attachments.
- No Laravel AI provider tools.
- No request concurrency limit. The package retries HTTP 429. It does not prevent it.
- The package does not check model names.
- The package does not set up your AI Gateway. Create and configure it in the Cloudflare dashboard.
- Reasoning controls depend on the model. `reasoning_effort` is ignored by some models.
- Timing and rate figures in these docs come from tests on one account. Your results can differ.

## FAQ

### Do I need AI Gateway?

No. Set only `account_id` to call Workers AI directly. Add `gateway` to get logs, analytics, caching and gateway retries.

### What is the difference between this package and the openai-compatible driver?

The Laravel AI `openai-compatible` driver works with the Cloudflare `/compat` URL. If you use one model for text and set `#[MaxTokens]` on every agent, that driver can be enough.

Use this package when you need one or more of these:

- A default token cap. Without a cap, Cloudflare stops most models at 256 tokens.
- An exception when a reasoning model spends its whole budget on thinking and returns nothing.
- `reasoning_effort` control.
- Neuron figures for cost tracking.
- Automatic retry of HTTP 429 and of Cloudflare edge errors.
- An AI Gateway with Authenticated Gateway turned on.

### Which token permission do I need?

`Workers AI: Read`.

### Does it work with Laravel Cloud, queues and Horizon?

The package is a normal Laravel AI provider. It makes HTTP calls with the Laravel HTTP client. Anything Laravel AI supports for queued agents works the same. Set `#[Timeout]` to fit your job timeout.

### Which model should I use?

For agents with tools, start with `@cf/openai/gpt-oss-120b`. For a cheap model, use `#[UseCheapestModel]`. Test your own prompts. See [Models](/guides/models/).

### Why does my reasoning model return nothing?

It used the whole token cap on thinking. See [Reasoning models](/guides/reasoning/).

### Can I use two Workers AI accounts?

Yes. Add two provider entries in `config/ai.php`, each with `'driver' => 'workers-ai'` and its own `account_id` and `key`. Give each entry its own name.

### Does the package send data anywhere except Cloudflare?

No. Requests go to the URL that your config resolves to.

### Is the package production ready?

Version 1.0.0 is the first stable release. It supports `laravel/ai` 0.9 to 1.3. Version 0.7.0 was tested against four consuming applications. Read the [changelog](/changelog/) before you upgrade.

### How do I report a bug?

Open an issue on [GitHub](https://github.com/meirdick/laravel-cf-workersai/issues).
