This page takes you from nothing to a working request. It needs about five minutes.

## Before you start

You need:

- A Laravel app with `laravel/ai` installed. See the [Laravel AI documentation](https://laravel.com/docs/ai-sdk).
- PHP 8.3 or later.
- A Cloudflare account.

## Install and configure

<Steps>
  <Step title="Install the package">
    ```bash
    composer require meirdick/laravel-cf-workersai
    ```

    This installs version `^1.0`. It works with `laravel/ai` 0.9 to 1.3.

    Laravel package discovery registers the service provider. You do not publish anything for this package.
  </Step>
  <Step title="Publish the Laravel AI config">
    Skip this step if `config/ai.php` exists.

    ```bash
    php artisan vendor:publish --provider="Laravel\Ai\AiServiceProvider"
    ```
  </Step>
  <Step title="Find your account ID">
    Sign in to the [Cloudflare dashboard](https://dash.cloudflare.com). Select your account. The account ID is the 32-character string in the dashboard URL after `/accounts/`. Do not paste a full URL. See [Find account and zone IDs](https://developers.cloudflare.com/fundamentals/account/find-account-and-zone-ids/).
  </Step>
  <Step title="Create an API token">
    In the Cloudflare dashboard, open your profile, then API Tokens, then Create Token. Give the token the `Workers AI: Read` permission. This is the permission name the package uses in its error message. The dashboard can name it differently, so look for Workers AI. Copy the token. Cloudflare shows it once. See [Create API token](https://developers.cloudflare.com/fundamentals/api/get-started/create-token/).
  </Step>
  <Step title="Set environment variables">
    ```env
    CLOUDFLARE_ACCOUNT_ID=your-account-id
    CLOUDFLARE_AI_API_TOKEN=your-api-token
    ```
  </Step>
  <Step title="Add the provider to config/ai.php">
    Add this entry inside the existing `providers` array:

    ```php
    'workers-ai' => [
        'driver'     => 'workers-ai',
        'key'        => env('CLOUDFLARE_AI_API_TOKEN'),
        'account_id' => env('CLOUDFLARE_ACCOUNT_ID'),
    ],
    ```

    The `driver` value must be `workers-ai` (or the alias `workersai`).
  </Step>
</Steps>

<Aside type="caution" title="Keep tokens out of git">
  Put the token in `.env`. Do not commit it. Do not put it in `config/ai.php` as plain text.
</Aside>

## Make a first request

```php
use function Laravel\Ai\agent;

$response = agent('You are a helpful assistant.')->prompt('Say hi.', provider: 'workers-ai');

echo $response->text;
```

Without a `model:` argument, the package uses `@cf/meta/llama-3.3-70b-instruct-fp8-fast`.

Pass any Workers AI model with `model:`:

```php
$response = agent('You are a helpful assistant.')->prompt(
    'Summarize this in one sentence.',
    provider: 'workers-ai',
    model: '@cf/openai/gpt-oss-120b',
);
```

## Make Workers AI the default provider

Set the default in `config/ai.php`:

```php
'default' => 'workers-ai',
```

Then you can omit `provider:`.

## Check that it works

The call returns text in `$response->text`. If it fails, see [Troubleshooting](/troubleshooting/).

Common first errors:

| Message starts with | Cause |
| --- | --- |
| `Workers AI requires an API token` | `key` is empty. Check `CLOUDFLARE_AI_API_TOKEN`. |
| `Workers AI requires an account_id or explicit url` | `account_id` is empty. Check `CLOUDFLARE_ACCOUNT_ID`. |
